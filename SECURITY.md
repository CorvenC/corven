# Security policy

Corven controls servers, containers and secrets, so security reports are taken seriously.

## Reporting a vulnerability

**Do not open a public issue.** Instead, open a **confidential issue** on GitLab:

1. Go to [gitlab.com/corvenc/corven/-/issues/new](https://gitlab.com/corvenc/corven/-/issues/new).
2. Check **"This issue is confidential"**.
3. Describe the problem, how to reproduce it, and its impact.

Only maintainers can see confidential issues. You will get an answer within 7 days.

## Supported versions

Corven has no release yet. Once it does, security fixes go to the latest minor version.

## Scope

In scope: the platform, its installer, its CLI, and the default configuration they create. Out of scope: vulnerabilities in the apps users deploy, and issues that need root access to the server first.
